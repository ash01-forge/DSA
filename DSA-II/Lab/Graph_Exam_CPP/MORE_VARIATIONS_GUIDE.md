# Additional variations: input, condition, and output changes

These 10 `MORE_` programs expand the earlier 30. Filenames describe the change. Read the opening comment in each file for its exact sample input and output.

No finite set can cover every possible graph question; these are further distinct patterns within the studied algorithms.

- `Dijkstra/MORE_01_change_required_checkpoint.cpp` — Shortest route required to pass through checkpoint V
- `Dijkstra/MORE_02_change_forbidden_edge.cpp` — Shortest route avoiding one closed road
- `Dijkstra/MORE_03_change_farthest_reachable_vertex.cpp` — Find farthest reachable vertex by shortest-path distance

- `Bellman_Ford/MORE_01_change_at_most_k_edges.cpp` — Cheapest route using at most K edges
- `Bellman_Ford/MORE_02_change_cycle_affects_destination.cpp` — Determine whether a negative cycle makes target cost unbounded

- `DSU/MORE_01_change_first_step_all_connected.cpp` — Earliest operation when every vertex becomes connected
- `DSU/MORE_02_change_dynamic_size_and_count_queries.cpp` — Dynamic MERGE, SIZE, and COUNT commands

- `Kruskal/MORE_01_change_total_savings.cpp` — Savings after replacing all roads with an MST
- `Kruskal/MORE_02_change_forbidden_edge_indices.cpp` — MST with certain routes forbidden by 0-based index

- `Prims/MORE_01_change_report_largest_mst_edge.cpp` — Prim finds largest selected edge in a minimum spanning tree
